# AgonFrogger

A "Frogger" game clone written in *BBC BASIC* for *Agon Light*.



The files are:

1. **Agonfrog.bas** -- source code of the program, written in BBC BASIC Z80 for Agon Light.

To run the program:

1. Download and copy the file **AgonFrog.bas** into your Agon Light's SD card.
2. Start Agon Light
3. LOAD and RUN **agonfrog.bas**
